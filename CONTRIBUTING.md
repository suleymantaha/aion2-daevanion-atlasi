# Katkıda bulunma

Hata düzeltmeleri, erişilebilirlik, mobil görünüm ve kaynakla kanıtlanan veri düzeltmeleri için pull request gönderebilirsiniz.

1. Depoyu fork edin, ayrı bir dal açın.
2. Değişikliği küçük ve tek bir amaca odaklı tutun.
3. `npm run validate`, `npm test`, `npm run check` ve `npm run build` çalıştırın.
4. PR açıklamasında değişikliği, test sonuçlarını ve ilgili ekran/kaynak kanıtını yazın.

## Veri ve skill düzeltmeleri

- Sınıf, tahta, satır/sütun veya node ID belirtin.
- Oyun bölgesi, sürüm ve tarih ekleyin.
- Tam skill adı/ID'si için doğrudan kaynak bağlantısı verin; varsa kişisel bilgileri temizlenmiş oyun ekranı ekleyin.
- Kaynak yetersizse önce issue açın. Başka sınıfın verisini kopyalamayın, bilinmeyen değerleri tahmin etmeyin.
- Üretilmiş JSON değiştiğinde importer ve validator da aynı sonucu üretebilmelidir.
- Sınıflar arasında kayıt karışmasını ve mevcut Sorcerer kayıtlarının kaybolmasını önleyin.

## Lisans ve gizlilik

Kod katkıları MIT lisansıyla kabul edilir. Üçüncü taraf veri için DATA_NOTICE.md sınırlarını koruyun. Token, OAuth dosyası, hesap e-postası, yerel kullanıcı yolu veya kişisel oyun kaydı göndermeyin.

Sitedeki “kaynakla kontrol edildi” ifadesi resmî veya canlı oyun doğrulaması anlamına gelmez. Kanıt olmadan “en iyi build”, “kesin doğru” veya yeni sınıf desteği iddiası eklemeyin.
